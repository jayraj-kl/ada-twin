# Feed pumps: datasheet

Ardenfield Pump Co. · Model AF-40 multistage boiler feed pump · Datasheet DS-AF40, revision C

## Duty

Horizontal multistage centrifugal pump for boiler feedwater, motor driven, two pumps installed side by side.

## Performance per batch

Rated transfer: one 500 L batch to the header at 7.2 L/s.

Cycle time: 70 s per batch.

Cycle-time variation (standard deviation divided by mean): 0.20.

Batches rejected for off-specification feedwater: 0.5% of batches.

## Notes

The cycle time includes valve changeover between batches. Variation comes from header back-pressure, which changes with boiler demand.

A run puts the crew against standard rules.

The crew works one shift in the twin. Its playbook and standard rules, the fixed way of running the floor that needs no agents, then work the same shift over many seeded days. Then you pick changes, run them as a trial on a copy of the twin, and apply only the ones that ship more.

The same days, every time.

The simulation is deterministic for a given seed. Day one replays the run’s seed and each further day takes the next, so standard rules, the crew and every change are measured against the same days. A gain is paired day by day, so one lucky or unlucky day cannot pass for the plant’s real performance.

Picks run as a trial on a copy of the twin. The twin itself is untouched, and only tested picks can be applied.
